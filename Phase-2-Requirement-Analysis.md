# Phase 2 – Requirement Analysis

## Project Title
PocketSmart AI: Your Smart Budget & Recommendation Assistant

## 1. Functional Requirements

### User Management
- Allow users to manage basic profile information.
- Allow users to select their preferred currency.
- Support light and dark mode.

### Income Management
- Enter monthly income.
- Update income information.
- Calculate available balance automatically.

### Expense Management
- Add expenses by category.
- Add custom expense categories.
- Edit and delete expenses.
- Track individual transactions.
- Store transaction date and description.

### Budget Management
- Set monthly budget limits.
- Compare planned and actual spending.
- Calculate budget utilization.
- Display budget status.

### Savings Goals
- Create savings goals.
- Set target amount and target date.
- Track current saved amount.
- Calculate remaining amount.
- Calculate required monthly savings.
- Display progress percentage.

### AI Assistant
- Allow users to ask questions about their finances.
- Analyze actual income, expenses, transactions, budgets and savings goals.
- Generate personalized recommendations using Google Gemini.
- Provide spending and savings insights.
- Clearly identify AI suggestions as educational information, not professional financial advice.

### Dashboard
Display:
- Monthly income
- Total expenses
- Remaining balance
- Savings amount
- Savings percentage
- Budget status
- Savings goal progress

### Reports and Insights
- Expense category analysis
- Income vs expense analysis
- Monthly spending trends
- Savings progress
- AI-generated insights

### Data Export
- Export transaction and budget information as CSV.

## 2. Non-Functional Requirements

### Performance
- Application should load quickly.
- Calculations should update efficiently.

### Usability
- Simple and user-friendly interface.
- Responsive design for mobile, tablet and desktop.
- Clear navigation and readable information.

### Security
- API keys must not be exposed in the client interface.
- Validate user inputs.
- Avoid sending unnecessary personal information to the AI service.

### Reliability
- Handle API failures gracefully.
- Handle invalid inputs and network errors.
- Provide useful error messages.

### Maintainability
- Use reusable components.
- Keep the project structure organized.
- Avoid unnecessary dependencies.

## 3. Hardware Requirements

- Computer or laptop
- Minimum 4 GB RAM
- Internet connection

## 4. Software Requirements

- Modern web browser
- Code editor
- GitHub account
- Web development environment
- Google Gemini API
- Git/GitHub for version control

## 5. Target Users

- College students
- Working professionals
- Individuals managing personal finances
- Users who want to improve budgeting and savings habits

## 6. Expected Result

The system should provide a functional and user-friendly budgeting assistant that helps users track their finances, manage budgets, monitor savings goals and receive AI-generated financial insights.
